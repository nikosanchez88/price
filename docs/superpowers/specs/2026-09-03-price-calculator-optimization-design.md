# 定价小程序轻量化优化设计

日期：2026-09-03

## 目标

把现有定价小程序收敛为一个简单、可靠、可离线使用的出厂价定价工具。本轮只保留出厂价、成本币种、手动汇率、目标毛利阶梯和反推毛利，不引入 IVA、杂费、平台佣金或其他费用模型。

## 本轮范围

### 保留

- RMB/CLP 出厂价币种切换。
- 用户手动填写 RMB→CLP 汇率。
- 自动记住上次填写的汇率；不提供固定默认值。
- 20% 至 90% 的现有目标毛利阶梯。
- CLP 售价向上取整到 10 CLP。
- 输入市场预期售价后反推毛利率与毛利金额。
- 一键复制 CLP 售价。
- PWA 安装与离线使用能力。

### 移除

- 额外杂费输入及其计算。
- IVA 开关、IVA 标记、19% 税率及全部相关计算和说明。
- “净利润”措辞。
- Tailwind CDN 运行时依赖。

### 暂不增加

- 平台百分比佣金和固定手续费。
- 运输、关税、支付费用、汇损、退货损耗等费用模型。
- 在线自动获取汇率。
- 多税率或可配置 IVA。

## 计算规则

所有计算只接受有限正数。汇率、出厂价和市场预期售价必须大于 0；空值表示尚未输入，不进行计算。

### 正向定价

对每个目标毛利率 `margin`：

```text
基础售价 = 出厂价 / (1 - margin)
```

- 出厂价为 RMB 时，先按 RMB 计算基础售价，再乘汇率得到 CLP。
- 出厂价为 CLP 时，直接以 CLP 计算基础售价。
- 最终 CLP 售价向上取整到 10 CLP。
- RMB 等值由最终 CLP 售价除以汇率计算，确保两列显示互相一致。

总成本行改名为“出厂价”，并按所选币种进行换算。它是信息行，不附加利润或税费。

### 反推毛利

市场预期售价固定以 CLP 输入：

```text
出厂价（CLP） = RMB 出厂价 × 汇率，或直接使用 CLP 出厂价
毛利（CLP） = 市场预期售价 - 出厂价（CLP）
毛利率 = 毛利（CLP） / 市场预期售价 × 100%
毛利（RMB） = 毛利（CLP） / 汇率
```

界面使用“预估毛利率”和“预估毛利（RMB）”，不把该结果称为净利润。

## 页面与交互

- 汇率输入保持可编辑，并通过 `localStorage` 保存最后一个有效值。
- 清空汇率时同时清除已保存值，并把提示恢复为“当前汇率：未设置”。
- 成本标签改为“出厂价”。
- 删除杂费输入和 IVA 开关后，顶部卡片保持紧凑的单列结构。
- 空输入不显示错误；输入零、负数或非有限数时显示字段级错误。
- 无效输入时清空价格表和对应反推结果，避免保留过时数据。
- RMB/CLP 切换只改变出厂价的解释币种，不自动改写已输入数字；标签会明确显示当前单位。
- 复制控件使用原生 `button`，成功后短暂显示确认状态；失败时显示可见提示，不伪装成功。

## 代码结构

### `calculator.js`

新增无 DOM 依赖的 ES 模块，负责：

- 数值校验。
- 汇率换算。
- CLP 取整。
- 正向价格阶梯计算。
- 反推毛利计算。

模块只接收数值和币种并返回结构化结果，便于独立测试。

### `script.js`

只负责：

- 获取和渲染 DOM。
- 处理输入事件与币种状态。
- 保存/恢复汇率。
- 调用 `calculator.js`。
- 显示输入错误、空状态和复制反馈。

浏览器脚本改为 ES module，并从 `calculator.js` 导入计算函数。

### `style.css`

- 把当前使用的 Tailwind 工具类改写为本地语义样式。
- 保留现有 iOS 风格视觉方向，不做整体重新设计。
- 添加可见的 `:focus-visible` 状态。
- 提升辅助文字和非激活按钮的颜色对比度。
- 保持 390px 左右手机宽度下无需横向滚动页面；价格表自身允许必要的横向滚动。

### `sw.js`

- 只预缓存同源本地资源，资源路径必须与 HTML 中引用完全一致。
- 安装时不依赖任何跨域请求。
- 激活时删除旧的 `price-tool-*` 缓存。
- 对同源 GET 请求采用网络优先、缓存回退策略，确保在线时获取更新、离线时仍能启动。
- 对导航失败回退到缓存的 `index.html`。

### `manifest.json`

- 保留现有应用名称和独立窗口模式。
- 修正主题色与页面主题一致。
- 图标声明只描述现有图标的真实尺寸，不在本轮生成新图标资产。

## 无障碍要求

- 所有可见表单标签通过 `for` 与控件关联。
- IVA 删除后不再存在无标签开关。
- 币种切换按钮暴露 `aria-pressed` 状态。
- 复制按钮具有可访问名称并支持键盘操作。
- 移除禁止缩放的 viewport 配置。
- 输入框、按钮均保留明显的键盘焦点指示。
- 普通文本达到 WCAG AA 4.5:1 对比度目标。
- 动态错误和复制状态通过适当的 live region 告知辅助技术。

## 错误处理

- 读取或写入 `localStorage` 失败时不阻断计算。
- Clipboard API 不可用或写入失败时显示“复制失败，请手动复制”。
- Service Worker 注册失败只记录诊断信息，不影响在线计算。
- 计算模块对无效输入返回明确失败结果或抛出可识别的参数错误，UI 不渲染 `NaN`、`Infinity` 或负汇率结果。

## 测试策略

新增 `package.json`，只使用 Node 内置测试运行器，不增加生产依赖。

单元测试覆盖：

- RMB 与 CLP 两种出厂价币种。
- 正向毛利阶梯公式。
- CLP 向上取整及 RMB/CLP 显示一致性。
- 反推毛利率和毛利金额。
- 空值、零、负数、`NaN` 和 `Infinity`。

浏览器验收覆盖：

- 汇率保存、恢复、覆盖与清空。
- 币种切换和字段单位变化。
- 无效输入错误状态。
- 复制成功和失败反馈。
- Service Worker 能激活、只缓存本地资源，并可在离线刷新时启动应用。
- 390×844 手机视口下的布局和关键键盘操作。

## 验收标准

- 页面中不存在杂费或 IVA 相关控件、文字和计算。
- 正常 RMB/CLP 正向计算与反推结果通过自动化测试。
- 零、负数和非有限数不会生成价格或毛利结果。
- 汇率没有默认固定值，但最后一个有效值能跨刷新恢复，清空后不再恢复。
- 在线首次访问后 Service Worker 成功激活，离线刷新仍显示完整样式和计算功能。
- 页面不加载任何第三方运行时资源。
- 自动化无障碍检查不再报告表单标签、禁止缩放或严重颜色对比问题。
