# 跨境定价助手

一个无需后端、可安装并支持离线使用的 RMB/CLP 出厂价定价工具。它通过手动汇率将出厂价换算为入库价，再生成毛利阶梯。

## 使用方法

1. 手动输入汇率，即 1 RMB 对应多少 CLP。这里也可以填写自行核算的综合汇率，将海运费、关税等到仓费用折算进去。
2. 选择 RMB 或 CLP 作为出厂价币种，然后填写出厂价。
3. 表格首行显示换算后的入库价；从毛利阶梯中选择并复制需要的 CLP 售价。
4. 输入市场预期售价，可以反推预估毛利率和 RMB 毛利金额。

汇率没有固定默认值。应用会记住最后一次填写的有效汇率；清空汇率后，保存的值也会被删除。

## 计算口径

```text
入库价 = 出厂价 × 手动综合汇率（出厂价为 RMB 时）
售价 = 入库价 ÷ (1 - 目标毛利率)
毛利率 = (售价 - 入库价) ÷ 售价
```

- CLP 售价向上取整到 10 CLP。
- RMB 等值根据最终 CLP 售价和当前汇率反算，确保两列显示一致。
- 本版本不单独计算 IVA、平台佣金、运费、关税或其他费用；折算进手动综合汇率的到仓费用会反映在入库价中。
- 实体店含 IVA 售价和网点实收价属于不同收入口径，不宜直接比较毛利率。需要标准销售毛利时，应确保售价与入库成本采用一致的含税或不含税口径。
- 页面结果是预估毛利，并非包含全部经营费用后的净利润。

## 本地运行

在项目目录中执行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。

Service Worker 需要通过 `http://localhost`、`http://127.0.0.1` 或 HTTPS 使用；直接双击打开 `index.html` 时不会启用离线安装功能。

## 测试

首次运行测试前安装开发依赖：

```powershell
npm install
npm test
```

测试使用 Node.js 内置测试运行器，并调用本机已安装的 Microsoft Edge、Google Chrome 或 Chromium 完成真实浏览器、离线缓存和无障碍验收。需要指定其他 Chromium 浏览器时，可设置 `BROWSER_PATH` 环境变量。
